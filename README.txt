# Holiday Fit PWA

A mobile-first workout, food, water and weight tracker designed for Android.

## Install on Samsung / Android
1. Upload the contents of this folder to a static HTTPS host (for example, a private GitHub Pages site or another static hosting provider).
2. Open the hosted HTTPS address in Chrome on your phone.
3. Open Chrome's menu (⋮) and choose **Install app** or **Add to Home screen**.
4. Launch Holiday Fit from your home screen.

A PWA must be served over HTTPS (or localhost) for installation and offline service-worker support. This ZIP is the app source bundle, not an APK and not a hosted website.

## Data and privacy
- Food, weigh-ins and checklists are stored locally in the browser using localStorage.
- Data is not sent to a server.
- Use Progress → Export backup regularly. Import backup restores a previous JSON export.
- Clearing Chrome site data can erase records. Keep a backup.

## Included
- 21-day challenge dashboard and settings
- Four strength routines, with workout completion logging
- Daily walking, protein and calorie habit checks
- Food diary with calorie and protein totals
- Water and weigh-in logs
- Weight trend chart
- JSON backup and restore

Nutrition targets are starting estimates only, not medical advice. Adjust based on your needs and professional advice. Exercise choices should be adapted to your fitness level and any injuries.
